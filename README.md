# Bank AI Assistant

Восстановленный React/Vite-прототип AI-помощника в мобильном банковском приложении для кейс-клуба.

**Исходная публикация:** https://bank-ai-assistant-case-club.netlify.app/  
**Эталонная сборка:** https://6a82a22aee37ee873290c571--bank-ai-assistant-case-club.netlify.app/ (17.08.2026)

Оригинальный Vite-проект был утрачен. 23 ноября 2026 года удалось скачать HTML, JS и CSS из Netlify, восстановить прикладную логику, перевести её в обычный React JSX и разделить приложение на модули. Историческая собранная версия сохранена в `deployed/`.

## Локальный запуск

Node.js 22+:

```bash
npm ci
npm run dev
```

Открой адрес, который выведет Vite, обычно http://localhost:5173.

Проверить production-сборку:

```bash
npm run build
npm run preview
```

Браузерные тесты:

```bash
npx playwright install chromium
npx playwright test
```

## Структура

- `src/App.jsx` — корневой экран и нижняя навигация.
- `src/screens/` — главный экран, предложение подписки, обзор AI, расходы, напоминания, накопления, чат, вкладки карт и платежей.
- `src/components/` — общие компоненты UI.
- `src/data/mockData.js` — демонстрационные финансовые данные и ответы чата по ключевым словам.
- `src/styles.css` — стили из оригинальной опубликованной сборки.
- `tests/browser.spec.js` — Playwright: переходы, функциональные сценарии, сравнение скриншотов с фиксированным оригинальным Netlify-deploy.
- `deployed/` — нетронутая историческая сборка с Netlify.
- `scripts/recover.py`, `scripts/reconstruct.py`, `scripts/modularize.mjs`, `scripts/normalize-source.mjs` — воспроизводимая история восстановления. Однократные миграции не предназначены для повторного применения к отредактированному приложению.
- `netlify.toml` — конфигурация сборки на Netlify (`npm run build`, публикация `dist`, Node.js 22).

## Поведение

Есть несколько интерактивных экранов: главная, предложение подписки, обзор AI-помощника, расходы, напоминания, накопления, чат, платежи и карты.

**Все данные демонстрационные.** Ответы в чате формируются локальной функцией `getMockReply` по ключевым словам, без вызовов LLM API. Платежи и подписка не обрабатывают настоящие деньги. Некоторые кнопки в прототипе не имеют функционального действия.

## Проверка соответствия

- Production-сборка Vite подтверждена через GitHub Actions.
- Playwright проверяет переходы между основными экранами, активацию подписки, расходные категории, переключатели напоминаний, накопления и ответы чата.
- Исходный вид сравнивается с неизменяемым деплоем Netlify от 17.08.2026 при разрешении 1280×900.
- В первой визуальной проверке совпадение скриншотов составляло 99,68% (главная), 99,77% (предложение) и 99,16% (обзор AI).

Исторические авторские комментарии, имена переменных и оригинальная организация исходников восстановлены частично. Реконструкция не подтверждает полную идентичность всех скрытых состояний или сценариев.

## Подключение существующего сайта Netlify

Репозиторий подготовлен к Git-based continuous deployment. Выполни однократную привязку в **существующем**, а не новом, Netlify-проекте:

1. Открой https://app.netlify.com/projects/bank-ai-assistant-case-club
2. Перейди в **Project configuration → Developer settings → Continuous deployment → Repository** (в некоторых версиях интерфейса: Build & deploy).
3. Нажми **Link repository**, выбери **GitHub**, затем `i-merkurev/bank-ai-assistant`. При необходимости предоставь Netlify GitHub App доступ к этому репозиторию.
4. Выбери production-ветку `main`. В `netlify.toml` уже указаны команда `npm run build` и publish directory `dist`.
5. Убедись, что первый Git-deploy прошёл успешно, и сравни новый сайт с эталоном.

**Привязка репозитория может сразу запустить публикацию в production.** Сохраняй исторический деплой по permalink, указанному выше. Не создавай второй сайт, если хочешь сохранить текущий URL.

После привязки push в `main` будет инициировать новую сборку Netlify; Pull Request сможет создавать Deploy Preview, если включены соответствующие настройки.
