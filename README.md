# Bank AI Assistant · восстановленный прототип

Восстановленная версия кликабельного [банковского AI-помощника](https://bank-ai-assistant-case-club.netlify.app/) для кейс-клуба. Исходники исходного Vite-проекта утрачены, но опубликованный бандл Netlify от **17 августа 2026 года** удалось скачать и реконструировать в отдельный React/Vite-проект.

**Статус:** браузерный прототип восстановлен, проект собирается через `npm run build`. Поведение следует опубликованной сборке; исходные компоненты JSX и sourcemap отсутствовали, поэтому компоненты сначала восстановлены из React JSX Runtime и отформатированы. Сквозное визуальное сравнение в браузере с оригинальной публикацией ещё не проводилось.

## Локальный запуск

Нужен Node.js 22+.

```bash
npm ci
npm run dev
```

После запуска открой адрес, который напечатает Vite (обычно `http://localhost:5173`).

Проверить production-сборку:

```bash
npm run build
npm run preview
```

## Какие экраны восстановлены

- Главный экран банковского приложения с балансом, операциями и предложением AI-помощника.
- Экран подписки (30 дней бесплатно, затем 399 ₽/мес.).
- Главный экран AI-помощника после активации.
- Анализ расходов с диаграммой и рекомендацией.
- Напоминания и переключение напоминаний.
- Накопления, прогресс финансовой цели.
- Чат с вопросами-подсказками и демонстрационными ответами.
- Вкладки «Платежи» и «Карты».

**Важно:** данные и ответы чата демонстрационные. В восстановленной сборке ответы формируются локально по ключевым словам, без вызова AI API и без реальных банковских интеграций. Нажатия на некоторые элементы носят демонстрационный характер.

## Структура

```text
src/main.jsx        React-приложение (из опубликованного JS, отформатировано)
src/styles.css      Оригинальные CSS-правила опубликованной версии
deployed/           Точная копия опубликованных HTML/JS/CSS
scripts/recover.py  Загрузка публичного деплоя Netlify
scripts/reconstruct.py  Однократное восстановление React-приложения из сборки
.github/workflows/  Восстановление и сборка через GitHub Actions
```

При восстановлении короткие имена компонентов из производственного JavaScript заменены на понятные: `App`, `HomeScreen`, `AssistantScreen`, `OfferScreen`, `AssistantOverview`, `ExpensesScreen`, `RemindersScreen`, `SavingsScreen` и `ChatScreen`.

Папку `deployed/` хранить как эталон исторической публикации. Не редактируй её в ходе развития продукта: меняй `src/`.

## Ограничения восстановления

1. Оригинальная структура файлов, комментарии, типы и исходные JSX-компоненты недоступны; часть имён и структуры реконструирована.
2. `src/main.jsx` пока использует вызовы `react/jsx-runtime`. Это корректный исполняемый React-код, но перед существенными доработками лучше переписать компоненты в обычном JSX и вынести их в отдельные модули.
3. Сборка в CI прошла. Полноценное ручное тестирование экранов, адаптивности и точного визуального соответствия ещё требуется.
4. Не подключать автоматический деплой из репозитория к действующему Netlify-сайту до проверки нового результата. Текущая публикация Netlify пока не изменена.
